# Система управления личными финансами

Консольный сервис на Java 17 для учёта доходов, расходов и бюджетов. Каждый аккаунт имеет собственный кошелёк и историю. Автор — Уразметов Лев.

## Сборка и запуск

Установите JDK 17 и Maven 3.9. Проверьте, что `mvn -version` показывает Java 17. Maven скачает зависимости для сборки и тестов автоматически. Для запуска JAR достаточно JDK 17.

```bash
mvn --batch-mode --no-transfer-progress verify
java -jar target/personal-finance.jar
```

Данные сохраняются в `.finance-data/` в текущем каталоге. Для отдельного профиля укажите `--data-dir path/to/data`. Опция `--help` выводит справку. В интерактивном терминале пароль вводится скрыто. При перенаправленном вводе пароль читается следующей строкой.

## Пример сеанса

Введите строки в интерфейсе приложения. Пароль в примере демонстрационный.

```text
register lev
demo-pass-123
login lev
demo-pass-123
category add | зарплата
category add | еда
category add | транспорт
budget еда | 1000
income 12000 | зарплата | 2026-11-01
expense 800 | еда | 2026-11-04
expense 150 | транспорт | 2026-11-05
expense 250 | еда | 2026-11-06
summary
report еда,транспорт | 2026-11-01 | 2026-11-30
export wallet-example.csv
logout
exit
```

После первого расхода в категории «еда» появится оповещение о 80%, после второго — о превышении на 50 RUB. Общий баланс составит 10800.00 RUB. Для проверки сохранения запустите приложение с тем же каталогом данных, войдите как `lev` и выполните `summary`.

## Команды

Одна строка — одна команда. Символ `|` разделяет параметры. Пробелы внутри названий категорий и путей поддерживаются. Символ `*` в отчёте обозначает все категории или открытую границу даты.

| Команда | Действие |
| --- | --- |
| `register ЛОГИН` | Создать аккаунт. Пароль вводится следующей строкой. |
| `login ЛОГИН` | Войти и загрузить кошелёк. Пароль вводится следующей строкой. |
| `logout` | Сохранить кошелёк и завершить сеанс. |
| `category add \| ИМЯ` | Добавить категорию. |
| `category rename \| СТАРОЕ \| НОВОЕ` | Переименовать категорию вместе с её бюджетом и операциями. |
| `category delete \| ИМЯ` | Удалить категорию без операций и бюджета. |
| `budget КАТЕГОРИЯ \| СУММА` | Установить или изменить лимит категории. |
| `unbudget КАТЕГОРИЯ` | Снять лимит. |
| `income СУММА \| КАТЕГОРИЯ [\| ДАТА]` | Записать доход. |
| `expense СУММА \| КАТЕГОРИЯ [\| ДАТА]` | Записать расход. |
| `summary` | Итоги, суммы по категориям, бюджеты и их остатки. |
| `report КАТЕГОРИИ \| С \| ПО` | Отчёт по списку категорий через запятую и включительному периоду. |
| `history` | История операций в порядке добавления. |
| `export ПУТЬ.csv` | Выгрузить кошелёк в новый файл. |
| `import ПУТЬ.csv \| REPLACE` | Заменить текущий кошелёк данными проверенного CSV-снимка. |
| `help` | Показать справку и примеры. |
| `exit` | Сохранить кошелёк и завершить программу. |

### Правила учёта

- Валюта — RUB. Сумма строго положительна, до 12 цифр перед точкой и до двух после неё. Дата — `YYYY-MM-DD`. При пропуске берётся текущая дата по часовому поясу системы.
- Логин содержит 3–32 символа `a-z`, цифры, `_` и `-`, начинается с буквы. Пароль — 8–128 символов, включая хотя бы один непробельный.
- Имя категории содержит 1–40 букв, цифр, пробелов, `_` и `-`, начинается с буквы или цифры. Логины и имена категорий приводятся к нижнему регистру. Перед записью операции создайте категорию.
- Остаток бюджета — лимит минус расходы этой категории за всё время. Период в отчёте фильтрует доходы и расходы, бюджеты остаются накопительными.
- Расход сверх бюджета или баланса сохраняется с уведомлением. Оповещения выводятся при достижении 80% лимита, исчерпании и превышении бюджета, нулевом и отрицательном балансе.
- Изменения сохраняются после успешной команды, а также при `logout`, `exit` и конце потока. Один каталог может одновременно открыть один процесс.
- CSV-снимок включает категории, бюджеты и операции. `REPLACE` подтверждает полную замену данных текущего аккаунта.

## Проверка

```bash
mvn --batch-mode --no-transfer-progress verify
java -jar target/personal-finance.jar --help
```

JUnit проверяет вычисления, валидацию, бюджеты, оповещения, файловое хранение, изоляцию пользователей, повторные сеансы CLI и импорт CSV. Результаты находятся в `target/surefire-reports/`, отчёт покрытия — в `target/site/jacoco/index.html`. Spotless проверяет форматирование. Для автоформатирования запустите `mvn spotless:apply`. GitHub Actions выполняет `verify` и проверяет запуск JAR.

## Архитектура

- `finance.core` — кошелёк, операции, авторизация, отчёты, оповещения и интерфейсы хранения.
- `finance.infra` — файлы аккаунтов и кошельков, блокировка каталога, CSV.
- `finance.cli` — цикл команд, терминальный ввод, справка и таблицы.
- `finance.Main` — аргументы процесса и сборка зависимостей.
